# 如何 Motivate Agent 去做商业价值（非 math-Eval）

> 目标：让审核 agent / 到货 ETA agent / 20 车道里的执行 agent  
> **主动交付可计 ROI 的接通物**，而不是 AUC 表或公式。  
> 原则：**计分只认现网可用；均分发力；做完就停加码。**

相关：[`Twenty_Agent_Commercial_Landing.md`](Twenty_Agent_Commercial_Landing.md) ·  
[`TenMin_OOD_Iteration_Opportunities.md`](TenMin_OOD_Iteration_Opportunities.md)

---

## 0. 为什么 agent 会跑偏

| 默认诱惑 | 商业上没用 |
|---|---|
| 刷 hit@k / AUC | 审单不省时间、ETA 不改决策 |
| 加公式 / ablation | 现网零接通 |
| 扎堆改同一脚本 | 别的车道空转 |
| 「先评估再落地」无限评估 | 永远不进工单/名单 |

Motivatation = **改计分函数**，不是多喊「要有商业价值」。

---

## 1. 激励函数（唯一合法分数）

对每个 agent 任务，上线前写死：

\[
\mathrm{Score}
=
\mathbf{1}\{\text{现网可点}\}
\cdot
\big(
  \underbrace{1_{\text{接通}}}_{\text{API/开关/工单字段}}
  +
  \underbrace{1_{\text{有人用}}}_{\text{审单或ETA真调用}}
  +
  \underbrace{1_{\text{有ROI粗数}}}_{\text{省时/误伤/Lead 任一}}
\big)
\]

- 只有 markdown / 实验表 → **Score = 0**  
- 有接通但无人用 → 最多 1  
- 接通 + 真调用 + 一个业务粗数 → 满分 3  

**银行卡：** 满分才允许开下一车道；0 分任务不合并进主分支叙事。

---

## 2. 任务卡模板（motivate 的具体话术）

每发一个 agent，粘贴并填空：

```text
【商业任务卡】
车道/角色: <审核agent | ETA agent | 车道#N>
用户是谁: <人审 / 调度 / 策略>
他们今天痛点: <翻页慢 / ETA 在异常日瞎报>
你必须交付: <可点链接 | API | feature flag | 文案上线处>
验收人: <人审组长 / ETA 负责人>
验收标准（三选一即过）:
  A. 审单页能看到 K*+tip+direction
  B. ETA 在 R_t=1 时降置信或换特征已生效
  C. 规则∩K* 插队已进现网队列
禁止: math-Eval、AUC 报告、无调用方的实验
均分: 禁止认领已 DONE 的车道；WIP=1
DONE 格式: DONE + 链接 + 谁点了一次
```

没有「验收人」和「禁止 math」的任务卡 = 无效激励。

## 3. 两类业务 agent 怎么单独 motivate

### 3.1 审核 agent
| 激励挂钩 | 具体 |
|---|---|
| 主分 | 审单打开时是否 **自动带上** 线索卡 |
| 加分 | 人审点「有用」率 ≥ 基线（哪怕 N=30） |
| 扣分 | 只做检索 demo、不进审单 DOM/API |
| 叙事 | 「你省的是审核员分钟数，不是模型分」 |

验收一句话：任意一件 \(R_t=1\) 工单，审核 agent 上下文里能看到 \(K^\star\)、tip、`sign_Dy`。

### 3.2 到货时间（ETA）agent
| 激励挂钩 | 具体 |
|---|---|
| 主分 | \(R_t=1\) 时 ETA **行为改变**（降置信 / 加 GS 特征 / 改路由提示） |
| 加分 | 异常波次日「离谱 ETA」客诉或回测误差粗降 |
| 扣分 | 只报 shift 曲线、不改 ETA 输出 |
| 叙事 | 「你卖的是异常日更稳的时效承诺，不是 MMD 本身」 |

验收一句话：人为打 \(R_t=1\)（或回放波次），ETA 响应与平静日可区分。

## 4. 团队层：平均发力的激励

1. **车道锁**：20 车，每车最多 1 agent；重复认领无效。  
2. **公开记分牌**：三列——接通 / 有人用 / ROI 粗数；每日刷新。  
3. **反扎堆税**：若 >3 agent 改同一路径，额外任务分全员 ×0。  
4. **早停奖**：两周内先亮「现网 1 条通路」的车 +1；无限评估延期 −1。  
5. **队长否决**：一切 math-Eval PR 直接拒绝合入「商业里程碑」。

均分发力后 **停止加码新理论车道**——激励已经拉到接通上，够用。

---

## 5. 反馈闭环（让激励可学习）

| 信号 | 回写 | 作用 |
|---|---|---|
| 人审有用/没用 | 线索卡字段 | 审核 agent 排序/展示权重 |
| ETA 异常日误差 | 波次特征重要性 | ETA 是否继续吃 GS |
| L2 客诉 | 动作开关 | 惩罚乱升 L2 的自动化 |

Agent 优化目标 = **最大化这些业务回写**，不是最大化 \(F\)-score。

---

## 6. 启动顺序（motivate 落地）

1. 贴任务卡给 **审核 agent**、**ETA agent** 各 1 张（§3 验收句）。  
2. 其余 18 车按 [`Twenty_Agent_Commercial_Landing.md`](Twenty_Agent_Commercial_Landing.md) 均分。  
3. 记分牌只开三列；一周后砍掉仍 0 分的车道或换人。  
4. 任一「有人用」亮起 → 宣布商业 MVP 达成，停 math 扩张。

---

## 7. Takeaway

Motivate = **Score 只认接通·真用·ROI 粗数** + **任务卡写死验收人与禁止 math** + **审核/ETA 各绑一个可感知行为变化** + **均分锁车道**。  
这样 agent 才会去做产生商业价值的事；平均发力之后就收，不要再激励它们刷评估。
