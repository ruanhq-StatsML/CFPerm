## 0. 层级（必须按这个顺序想）

```text
① 业务结果动了没？     sign_Dy = sign(Δȳ)     ← 唯一案由开关
        │
        ├─ pos → S1 刷量族
        ├─ neg → S2 灌入族
        └─ flat→ S3 漂移族
        │
② 主 tip 桶（去量 content）  ← 定「哪条队 / 查什么」
        │
③ 评估切片（可叠加，不定族）
```

**禁令：** 不许用 ops AUC、不许用 intensity 高、不许用 Jaccard，去改 S1/S2/S3。

## 1. S1 / S2 / S3：怎么刻画 · 怎么评估

### 1.1 刻画（定义 = 业务词典）

| 族 | 刻画（一句话） | 必要信号 | 广告体感 |
|---|---|---|---|
| **S1 刷量** | 块上成功 **变多**，且像被操控/假成功（或真爆款待辨） | `sign_Dy=pos` | 「转化好得离谱」 |
| **S2 灌入** | 块上成功 **变少**，差流/劫持/打压残留灌进来 | `sign_Dy=neg` | 「曝光还在，转化被冲了」 |
| **S3 漂移** | 结构 tip 在动，成功 **没跟着动** | `sign_Dy=flat` 或 Dy 缺失 | 「改了策略，转化没动」 |

极性相反 ⇒ 查法相反；**不能**「有 tip 就叫刷量」。

### 1.2 评估（看板怎么打分，仍然服务案由）

| 步骤 | 评估量 | 通过线（业务） |
|---|---|---|
| A. 定族 | 相邻窗 `mean_Δȳ` → `sign_Dy` | 有符号才定 S1/S2；缺失→按 S3 保守 |
| B. 定队 | content top（`credit/share/span/covisit`） | 有末跳 tip + S1 → 末跳队；短跨度 + S2 → 差会话队 |
| C. 排除假动作 | ops 是否只是买量基线 | ops AUC 高 **不**加分给「作弊」 |
| D. 稳不稳 | Jaccard / stride 对照 | 名单乱跳 → 仍 L1，先别升 |

**本机边看板样例：** `Δȳ≈−0.008` → **S2**；content 仍有 `i_credit_last` → 「灌入倾向 + 路径结构盯梢」，不是 S1。

### 1.3 评估清单（人审可勾）

```text
[ ] sign_Dy 是什么？
[ ] 若 pos：content 有没有 last/credit？有→末跳队；无→弱刷量/爆款辨
[ ] 若 neg：有没有短会话/差流线索？勿先骂创意变差
[ ] 若 flat：只查策略/定向/轮换；禁止自称刷量
[ ] ops 一行是否仅买量基线？是→写进工单「量的故事」，不限投
```

## 2. Intensity × Credit：是什么、不是什么

**是：** 在**已经定族之后**，把边切成四格，看「量×末跳」组合下故事是否同构。  
**不是：** 新的 S4 案由；不能 `I_high∧C_high` 就叫刷量。

| 格 | 业务问题（在给定 S 族下） | 评估看什么 |
|---|---|---|
| **I_high × C_high** | 大买量且末跳重——钱是否堆到末跳？ | content top 是否 credit/share；S1 时优先辨爆款 |
| **I_high × C_low** | 量大但归因弱——量在空转？ | 效率/落地；转化常差 |
| **I_low × C_high** | 少曝光仍高归因——路径故事更「纯」 | content 权重↑；少被量基线淹没 |
| **I_low × C_low** | 两弱 | 常 y≈0 / 无 pairs；降抽检，别硬刷 AUC |

**和 S 族的拼接例子：**

- `S1` + `I_high∧C_high` → 「放量期末跳变重」：末跳队，辨真爆款  
- `S2` + `I_high∧C_low` → 「还在买量但转化掉、归因弱」：差流/落地，不是限投强度  
- `S3` + 任一格 → 只描述结构，不升刷量/灌入名

跑法：`--cross`（`run_subset_pairwise_analysis.py`）。

## 3. 子集 × ops/content 再跑相邻窗

业务目的：**同一案由下，量故事和路径故事是否在子群里拆得开。**

```text
for subset in {all, I_high, I_low, C_high, C_low, I×C 四格, ...}:
    for panel in {ops, content}:
        sort → pairwise(N) → (AUC, Jaccard, Δȳ, top)
```

| 面板 | 业务问题 | 评估 |
|---|---|---|
| **ops** | 这子集里买量基线还在不在？ | AUC 高=量故事仍在；**仍≠限投** |
| **content** | 去掉量，路径/末跳还能否传？ | top=credit → 末跳候选；AUC 掉→量曾主导 |

读法纪律：

1. 先看该子集的 **Δȳ**（族不能被子集改写；子集 Δȳ 只作局部体感）  
2. 再并排 ops / content 两行  
3. gap 大 → 工单先写买量基线，再写路径  
4. 只有 content 在某子集「活着」→ 人审权重给那一格

## 4. Stride 重叠：干什么用

| | 默认 pairwise | stride=N/2 重叠 |
|---|---|---|
| 切法 | 窗互不重叠 | 窗重叠一半 |
| 业务问题 | 批次边界清晰时的主结论 | **切窗运气**：放量尖峰是否刚好切在边界 |
| 评估 | 主报 | 与默认对照：族/top/Jaccard 是否同向 |

**同向** → 结论稳，可写进值班纪要。  
**大变** → 标注「对切窗敏感」，**保持 L1**，先别升动作。  

Stride **不改** S 族定义；只评估稳健性。

## 7. 一分钟复述（先业务）

1. **先问转化升/降/平 → 定 S1/S2/S3。**  
2. **再问去量后 tip → 定查法。**  
3. intensity×credit、ops/content、stride = 把查法切片做稳，**不是新案由。**  
4. 买量基线 AUC≈0.99 = 放量正常故事，不是作弊，不限投。
