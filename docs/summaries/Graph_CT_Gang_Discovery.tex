\begin{abstract}
We map locked attribution to continuous-time \emph{gang / cohort}
discovery: OnlineRFPerm on MMD/PO/cmean answers \emph{when};
Leiden (or merchant) supplies entity keys; Drill
rank-average(MMD,PO,cmean) answers \emph{which block};
one FSDS + signed direction answers \emph{what tipped}.
Communities are retrieval supports, not ATE subgroups;
modularity $Q$ never enters the Drill gate.
