> 本包只做 L1 可读分流；场景 = 运营词典，**不是**自动定罪分类器。

## 0. 一张总图（三族 + 修饰）

```text
块上结局方向 sign_Dy
        │
        ├─ pos  成功率升 ──► 【刷量族】互点 / 养号 / 末跳操控 / 真爆款(要辨别)
        ├─ neg  成功率掉 ──► 【灌入族】劣质短会话 / 劫持残留 / 被打压后垃圾流
        └─ flat 成功率平 ──► 【漂移族】供给·推荐·活动改了结构，慎升强动作

修饰（可叠在任一极性上，不单独定罪）：
  · 共点变密     → 提高抽检，仍 L1
  · 热度-活跃错配 → 辨别爆款 vs 刷热
  · 波次偏老     → 同队优先清（SLA）
```

**审核第一句话只问：** 这波是「成功变多」「成功变少」还是「结构漂了但成功没动」？

## 1. 刷量族 vs 灌入族（必须先分清）

这两类最容易混；**极性相反，查法相反**。

| | **刷量族（S1）** | **灌入族（S2）** |
|---|---|---|
| 一句话 | 块上 **假成功/被操控的成功** 变多 | 块上 **成功变少**，灌进差流量或劫持残留 |
| `sign_Dy` | **pos**（\(\Delta\bar y>0\)） | **neg**（\(\Delta\bar y<0\)） |
| 业务体感 | 「这堆货/号 click 突然好得离谱」 | 「曝光还在，转化被污水冲了」 |
| 典型 tip | `i_share_last` / `i_credit_last` **+**（成功压在末跳） | `u_span_sec` **−**（会话变短）+ 触达/共现异常 |
|  | `u_span_sec` 短刷（短窗狂点） | 共现/规模 tip 与「差会话」同向 |
| 人审先看什么 | 成功路径是否末跳劫持；互点/养号；是否真爆款 | 低转化会话是否灌进 \(K^\star\)；是否刚被打压后的残留流 |
| 易误判成 | 正常大促爆款 | 「商户突然变差」或供给不足 |
| 禁区 | 无 tip、仅 ID 名单就限频/封号 | 成功率掉 ≠ 商户作恶 |
| 默认动作 | **L1 盯梢**；连续加剧才议 L2（本包 Out） | 同左 |

### 1.1 对照例子（同一套尺子）
| 卡上看到 | 先归哪族 | 队列话术 |
|---|---|---|
| `sign_Dy=pos`，`i_share_last=+` | 刷量族 | 末跳份额升且成功升 → 末跳/刷量队 |
| `sign_Dy=pos`，规模 tip 升但无 last | 刷量族（弱）或真爆款 | 先对爆款核对，仍 L1 |
| `sign_Dy=neg`，`u_span_sec=−` | 灌入族 | 跨度变短且成功掉 → 劣质短会话灌入 |
| `sign_Dy=neg`，共现变密 | 灌入族 + 共点修饰 | 差流可能成团灌入，提高抽检 |
| `sign_Dy=flat`，路径 linear tip | **不是**刷量也不是灌入 | 漂移族：先查活动/推荐/库存 |

### 1.2 为什么不能「有 tip 就叫刷量」
- tip 只说 **哪类图特征在 \(K^\star\) 上漂移**  
- **有没有「假成功」看 `sign_Dy`**  
- flat + `i_share_linear`（当前样例）= 路径结构变了，**成功没动** → 漂移，不是刷量

## 2. 漂移族（S3）——当前样例就在这

| | |
|---|---|
| 一句话 | X（图特征）漂了，块上 click/convert **没跟着动** |
| `sign_Dy` | **flat** 或 Dy 缺失（产品上当 flat 读，并应标 `dy_missing`） |
| 典型 tip | `i_share_linear` / `i_credit_linear` / first 份额 / 触达·曝光规模 |
| 人审先看什么 | 活动、推荐改版、库存、流量结构；**慎升强动作** |
| 和刷量/灌入的边界 | 一旦后补到可靠 `sign_Dy=pos/neg`，再改族，不在 flat 上赌 |

当前 `tencent_gr_w1w2_mmd_po_fsds`：顶 tip 是路径线性份额/归因 + 共现；direction 空 → **按 S3 讲故事**，不要硬讲成刷量。

## 3. 修饰场景（叠在三族上面，不单开「案由」）

| ID | 名字 | 何时出现 | 怎么用 |
|---|---|---|---|
| **S4 共点** | `i_n_covisit_*` 顶 | 任一极性 | 「可能成团」→ 抽检变密；**不**对外喊团伙认定 |

**S6 内容复用**：换 tip 词典（互粉/种草），**场景轴仍是 pos/neg/flat 三族**，只是话术换成内容安审语言——不另起一套欺诈分类。

## 4. 审核台上的固定读卡顺序（业务操作）

```text
1. 看 sign_Dy
     pos → 刷量族入口
     neg → 灌入族入口
     flat/缺失 → 漂移族入口（慎升）
2. 看主 tip（卡上第一队列桶）
     last/share     → 末跳子队
     u_span 短      → 短刷 / 短会话灌入（看极性）
     linear/规模    → 路径或供给结构
     covisit        → 加上 S4 共点修饰
3. 人可改队：词典建议 ≠ 终裁
4. 只输出 L1 上下文；要 L2/L3 另流程
5. 打标 useful/not_useful：评「这张卡有没有帮你少走错队」
```

### 4.1 「走错队」长什么样（给反馈 note 用）
| 实际 | 卡建议 | note 示例 |
|---|---|---|
| 真是末跳刷 | 漂到漂移队 | not_useful：应去末跳 |
| 真是活动改版 | 写成刷量 | not_useful：flat 应慎升 |
| 帮你直接去了对的抽屉 | — | useful：少翻了规则页 |

## 6. Takeaway（就记这三句）

1. **刷量 = 成功变多（pos）；灌入 = 成功变少（neg）；漂移 = 成功没动（flat）。**  
2. tip 只决定「进哪条抽屉」，不单独定案由。  
3. 当前样例先按 **S3 漂移** 讲；补齐 direction 之前，不要假装是刷量。

其它（角色、闭环、灰度）都挂在这张场景图下面说；**场景没捋清之前，不扩 feature。**
