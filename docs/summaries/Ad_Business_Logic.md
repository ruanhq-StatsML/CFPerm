## 0. 一句话业务主张

广告异常审出要先分清两件事，**不能混成一句「模型不准」**：

1. **量在不在**（买量 / 曝光强度）——预算、定向、竞价、放量  
2. **路径像不像被操控**（末跳 / 归因份额）——落地、劫持、刷末跳、真爆款  

本看板故意拆成 **ops（留量）** 与 **content（去量）** 两行，就是为了逼出这两句分开的话。

## 1. 业务对象是什么

| 业务说法 | 表里是什么 |
|---|---|
| 一条「投放触达关系」 | 一行 `(用户, 创意/商品)` 边 |
| 这批货/号最近热不热 | 按 `e_last_ts` 排序后，每 1000/2000 条边一个业务窗 |
| 这窗转化好不好 | 窗内 `y_convert` 均值；相邻窗差 = `Δȳ` |
| 广告主 | 上游 merchant / `item_feat.122`（审出挂账户用） |

为什么按**边数**不按「每小时」：投放日志会突发（大促、放量、停投），同小时边数可差一个数量级；业务上「看一批差不多大的样本」比「看整点钟」更稳。

## 2. 漏斗三句（人对人对）

```text
曝光有没有 → 点击顺不顺 → 转化成不成
   ops 强度          （中间）         Y + content 末跳
```

| 业务问题 | 看哪一行 | 别误读成 |
|---|---|---|
| 这波是不是「花钱堆出来的」？ | ops top≈曝光强度，AUC 很高 | 「作弊了」——强度往往是正常买量 |
| 去掉花钱因素，路径还怪不怪？ | content top≈`credit_last`/`share_last` | 「已定罪末跳」——只是 L1 候选 |
| 转化变多还是变少？ | `sign_Dy`（Δȳ 符号） | 有 tip 就叫刷量——没有极性不能叫 |

## 3. 三族案由（广告体感）

和刷量/灌入/漂移总表一致，换成投放口语：

| 族 | 业务体感 | 人审第一刀 |
|---|---|---|
| **S1 刷量** | 「这账户转化突然好得离谱」 | 末跳是否被抬；是不是大促真爆款 |
| **S2 灌入** | 「曝光还在，转化被污水冲了」 | 差流、落地挂了、刚被打压的残留 |
| **S3 漂移** | 「结构变了，转化没动」 | 策略/定向/创意轮换；慎限投 |

本机样例：`Δȳ<0` → **S2**。话术应是：

> 相邻窗转化在掉。先查差流和落地，**不要**先骂创意素材变差；  
> ops 说强度仍在传（量还在），content 仍甩出末跳特征 → **差流 + 路径结构** 双盯梢，L1。

---

## 4. 买量基线（曝光强度）——业务上为什么要单列

投放里「转化模型变准了」最常见的假象是：**你只是多买了量**。

- ops 面板几乎总把 `e_log1p_exp` / 物品曝光规模顶上去，且 AUC≈0.99  
- 业务含义：**「有量的边更好转化」在相邻批次里一直成立**——这是买量世界的基线，不是新发现的作弊因子  
- 因此工单必须有一行：

> **买量基线**：强度可传。本卡不据此限投、不据此改出价。

子集上（大曝光创意 vs 小曝光创意）ops 都≈0.99 → 基线 **不挑创意体量**，更说明它是全局买量逻辑，不是某一两个爆款账号的故事。

---

## 5. 末跳 / content 十四维——业务上为什么要去量

去量之后还进 top 的，才配进「创意/落地/路径」讨论：

| 特征族 | 投放解读 |
|---|---|
| `i_credit_last` / `i_share_last` | 转化功劳是否堆在末跳创意 |
| `i_credit_first` / `*_linear` | 首跳或路径分摊是否异常 |
| `i_n_covisit_*` | 共点变密 → 抽检↑，仍不对外喊团伙 |
| `u_span_sec` | 会话过短 → 劣质短会话嫌疑（灌入侧常用） |

业务动作默认 **L1 盯梢 / 提审优先级**，不是自动停投。  
`credit_low`（归因最差那批边）转化率可到 0 → 说明「没归因份额的货基本不转化」；审出价值在 **credit_high** 切片，不在低归因空集上硬刷 AUC。

## 6. 人审读卡顺序（广告值班）

1. **转化极性**：升 / 降 / 平？ → 定 S1/S2/S3  
2. **ops 一行**：买量基线是否仍在？（几乎总会在）  
3. **content 一行**：末跳/份额有没有进候选？  
4. **gap**：ops 远高于 content → 「大半是量」；先报量，再报路径  
5. **子集（可选）**：大曝光 vs 小曝光；高归因 vs 低归因 —— 故事是否只在某一档成立  
6. **禁区**：AUC 高 ≠ 上线出价模型；tip ≠ 定罪；flat ≠ 刷量

## 7. 和投放系统其它模块怎么分工

| 模块 | 答什么 | 本看板 |
|---|---|---|
| 出价 / 预算 | 怎么花更值 | **不答**（且禁止用探针 AUC 冒充） |
| 创意优选 | 哪条素材好 | content shortlist 可供参考，不作最终分 |
| 风控限频 | 要不要收紧 | 仅 L1 线索；L2+ 另包解冻 |
| 审出加速 | 人先看哪类案 | **主战场** |

## 8. 本机业务结论（可写进周报）

1. 用**边样本窗**看投放批次，比死磕整点更贴突发流量。  
2. **买量强度**是稳传基线——报工单时先承认「量的故事」，避免误伤。  
3. **去量后的末跳/份额**才是审出候选；对齐刷量/灌入族时必须带转化极性。  
4. 当前样例偏 **转化下行（S2）**：优先差流/落地/打压残留，而不是先砍创意。  
5. 一切动作默认 L1；**不上线 HGB、不定罪、不自动限投**。
