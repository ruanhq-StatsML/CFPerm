% Rolling PO-learner refit with a uniform default.

\paragraph{Uniform unless the batch is clearly different.}
Always-on $\sqrt{\mathrm{PO}}$ IPTW reweights every hop, including hops
where $P(Y\mid X)$ did not move. That is why uniform is slightly better on
quiet streams. The fix is a \emph{gate}: stay uniform until the refit
PO-learner says T=1 is clearly riskier than T=0.

\paragraph{Refit when a new batch arrives.}
Do not reuse a frozen probe. At hop $t$ (batches $0,\ldots,t$ observed),
\begin{equation}
  T{=}0:\ \text{most recent control } B_{t-2},
  \qquad
  T{=}1:\ B_{t-1}\cup B_t
  \ \text{(上一批 and 这一批)}.
\end{equation}
On the first hop, fall back to $T{=}0=B_0$, $T{=}1=B_1$.
Refit the DR PO-learner
$\varphi=(\mu_1-\mu_0)+(T-\pi)(Y-\mu_T)/(\pi(1-\pi))$ on this assignment
only, with the same family as the next-step predictor (RF / XGBoost / MLP;
not Ridge). Instance score $r_i=\varphi_i^2$. Contrast
\[
  \rho_t = \bar r_{T=1}\,/\,\bar r_{T=0}.
\]
If $\rho_t < \gamma$ (default $\gamma=1.25$), weights are uniform.
If $\rho_t \ge \gamma$, $w_i \propto \sqrt{r_i}$ on T=1 rows (mean-1,
clipped). The next-step model trains on T=1 and is scored on $B_{t+1}$.

\paragraph{Adaptive train set (the re-adjustment).}
Gate uses the hop contrast $B_{t-1}$ vs $B_t$.
If the gate is quiet, train on $B_{t-1}\cup B_t$ with uniform weights
(more data, same $P(Y\mid X)$).
If the gate fires, drop the old batch and train on $B_t$ --- that is the
re-adjustment on a clearly different batch. Pair-always PO is the wrong
default: it mixes pre- and post-shift rows on the cut hop.
The PO-ratio $\rho$ is a \emph{pocket} detector (T=1 riskier than T=0).
A global map flip needs the residual hop ratio instead.

\paragraph{Hop variant.}
$T{=}0=B_{t-1}$, $T{=}1=B_t$, train on the new batch only. Pair uses more
recent mass; hop is the tighter ``new vs immediately previous'' contrast.

\paragraph{What else (same slot).}
\textit{switch}: same train-set rule as adaptive, but $w=1$ --- isolates
dropping the old batch from $\sqrt{\mathrm{PO}}$ IPTW.
The PO-ratio gate $\rho=\bar r_{T=1}/\bar r_{T=0}$ misses a \emph{global}
concept flip (both sides' $\varphi^2$ jump, so $\rho\approx 1$).
The residual gate
$\rho^{\mathrm{res}}=\mathrm{err}(B_{t-1}\!\to\! B_t)\,/\,\mathrm{err}(B_{t-2}\!\to\! B_{t-1})$
is consecutive-batch next-hop error, \emph{not} $K$-fold CV.
Quiet $\to$ train last two, uniform. Fire $\to$ drop the old batch.
\textit{resid} then trains on $B_t$ only; \textit{resid\_po} also applies
refit $\sqrt{\mathrm{PO}}$ weights on that new batch.
Soft gate: $w \leftarrow (1-\lambda)\mathbf{1}+\lambda w_{\mathrm{PO}}$ with
$\lambda=\mathrm{clip}((\rho-\gamma)/(2\gamma),0,1)$.
\textit{oracle}: knows $\texttt{concept\_at}$; train-set upper bound.
DRE stays the $X$-only baseline; it still ignores label risk.
The first post-cut batch is structurally unpredictable from labels
(when scoring $B_4$ the hop $B_2$ vs $B_3$ is still quiet).
Real consecutive streams (Metro Interstate hourly traffic, NYC green
taxi by pickup clock, California latitude, diabetes readmission
source$\to$target) use the same hop protocol. Uniform on the last two
batches is the default there too; DRE and always-on $\sqrt{\mathrm{PO}}$
hurt. EMA of $w$ across hops is left for later.
