\begin{abstract}
When online risk rises, teams often default to ``OOD high $\Rightarrow$ retrain.''
That conflates several diseases into one expensive action.
We deliver a \emph{product justification proxy}:
\textbf{Magnitude $\times$ Variance of PO-risk}, estimated by a cheap bootstrap over
sub-environments.
The proxy is deliberately low inference-cost: even with bootstrap it answers
\emph{what to do next} in seconds on CPU---hold, conformal-calibrate, or
VAI-guided freeze---before any heavy retrain.
Empirically, a four-way triage (quiet / benign / malignant-sparse / malignant-dense)
reaches family accuracy $\approx 0.92$ on HC3 and news20 boards
(HC3-all branch accuracy $1.00$).
\end{abstract}

\section{Product claim (one screen)}

\begin{quote}
\textbf{Mag$\times$Var of PO-risk is a justification proxy for actuator choice.}
Magnitude asks whether the LIVE batch is sick;
Variance asks which disease (uniform benign lift vs concentrated malignant mass).
Bootstrap keeps the sensor cheap; the decision tree maps the sensor to medicine.
\end{quote}

\noindent
This is deliverable now: the reasoning cost is low, so product can run the gate
on every hop without waiting for GPU retrain budgets.

\section{PO-risk and the two axes}

\paragraph{Unit risk.}
With labels $Y$,
\begin{equation}
  \mathrm{PO}_i \;=\; 1-\hat p(Y_i\mid x_i)
  \qquad\text{(supervised proxy; DR / PermuCATE $\varphi$-risk is plug-compatible).}
\end{equation}

\paragraph{Magnitude.}
\begin{equation}
  \mu \;=\; \mathbb{E}[\mathrm{PO}_i]\,.
\end{equation}

\paragraph{Variance (bootstrap sub-environments).}
Draw $K$ windows $b=1,\ldots,K$ of size $w\approx n/5$;
$r_b=\mathrm{mean}_{i\in b}(\mathrm{PO}_i)$. Then
\begin{equation}
  s \;=\; \mathrm{Std}(r_1,\ldots,r_K)\,.
\end{equation}
Optional merge index for dashboards:
\begin{equation}
  J \;=\; \Delta\mu\cdot\bigl(1+\kappa\cdot \Delta s_{+}\bigr),\quad
  \Delta s_{+}=\max(\Delta s,0)/s_{\mathrm{REF}}\,.
\end{equation}

\paragraph{Why merge (justify).}
Magnitude alone: benign synonym and malignant injection both raise $\mu$.
Variance alone: sampling spikes without mean lift can false-alarm.
Joint Mag$\times$Var is the minimal statistic that \emph{resolves}
benign vs malignant shift when both sit in an ``OOD$\uparrow$'' band.

\vspace{0.5em}
\noindent
\textbf{VAI} (variable attribution importance):
perturb token $j$ $\to$ re-forward $\to$
$a_j=|\mathrm{PO}^{\mathrm{drop}\,j}-\mathrm{PO}|$;
concentration of $\{a_j\}$ localizes lexical blocks under sparse attack.

\paragraph{Low reasoning cost.}
The gate is CPU bootstrap of unit PO (seconds), not a model refit.
Even with bootstrap, product can answer on every LIVE hop:
\emph{hold / calibrate / freeze-where-VAI-points}.
Heavy medicine (retrain, full adv-aug) is reserved for unstable-variance branches.

\paragraph{Economic polarity.}
Under a cost model $C=c_{\mathrm{FP}}\cdot\mathrm{FP}+c_{\mathrm{FN}}\cdot\mathrm{FN}$
(e.g.\ $\$50$ FP / $\$20$ FN), benign medicine cuts FP;
malignant medicine cuts FN.
Mag$\times$Var is the allocation rule between those ledgers.

\section{Delivery message}

\begin{enumerate}[leftmargin=*]
  \item \textbf{Sensor:} Mag$\times$Var of PO-risk (bootstrap $s$).
  \item \textbf{Proxy role:} justifies \emph{actuator choice}, not model SOTA.
  \item \textbf{Cost:} low inference; bootstrap is acceptable on-call.
  \item \textbf{Tree:} stable variance $\to$ mean gate;
        unstable $\to$ kurtosis / VAI for sparse vs dense.
  \item \textbf{Ship:} triage gate in front of conformal / freeze / human review.
\end{enumerate}

\section*{One-line close}
Mag$\times$Var of PO-risk is a cheap, bootstrapable justification proxy that
turns ``risk went up'' into ``here is the right next action''---fast enough for
product hops, sharp enough to stop mixing benign FP costs with malignant FN tails.
