\section{Multi-Modal Attribution use-case: cross-modal contamination}
\label{sec:cross-modal-contamination}

\paragraph{Opportunity.}
Multimodal systems fail when one modality's shift \emph{leaks into} another's
scores or into the joint predictor---not only when a single block's marginal
$P(X_m)$ moves.
The FSDS stack already measures modality shares (RF-Domain / MMD / PO-risk)
and hop actuators (modality-$\pi$, PO masks).
The missing product story is \textbf{contamination}: attribute \emph{which
layer} the leak lives at, then pick the cheapest actuator.

\subsection{Definition}
Write $X=(X_v,X_a,X_t)$ and learner $f$.
\textbf{Contamination} covers support leak (shift in $m$ read through
correlated $m'$), concept leak ($Y\mid X$ or cross-modal map drifts with
quiet marginals), fusion soak (late fusion lets a noisy block dominate),
and structural nulls (window-invariant blocks---e.g.\ clip-level text on the
MSR-VTT extract).
Batch $W$ on that board is the early vs.\ late window split
\emph{inside} each video.

\subsection{Layer stack}
Attribute outside-in; each layer gates the next.
Do \textbf{not} jump to patch masks before modality shares; do \textbf{not}
reweight training features by PO VIMP (lost to \texttt{hop\_ridge} on Amazon).

\small

\bottomrule
\end{tabular}
\end{center}

\paragraph{Contamination score.}
On hop $t{-}1\to t$, donor $m$, target head $m'$ (or joint $Y$):
\[
  C_{m\to m'}
  =
  \Delta\mathrm{MSE}^{(-m)}
  -
  \Delta\mathrm{MSE}^{(\mathrm{mask}\,m)}.
\]
Large LOGO + small mask $\Rightarrow$ fusion soak ($\pi$ / fusion gate);
large mask + stable $\pi$ $\Rightarrow$ localized donor concept (mask);
both large $\Rightarrow$ compound (escalate).

\subsection{Where the opportunity is}
\begin{enumerate}\itemsep2pt
  \item[\textbf{O1.}] \textbf{Stop blaming the wrong modality.}
        Single-share pies over-credit the tallest block.
        MSR-VTT RF shares video$/\!$audio$/\!$text $\approx 0.77/0.19/0.04$,
        but text's near-zero is \emph{structural} on this extract---not
        ``language unused.''
        L1$\times$L3 tickets name donor$\to$target edges.
  \item[\textbf{O2.}] \textbf{Cheapest actuator before retrain.}
        Locked recipe: Amazon $\to$ heatmap \texttt{hop\_ridge};
        multimodal $\to$ modality-$\pi$;
        PO-risk $\to$ \textbf{mask only}.
        Mild L3 $\Rightarrow$ $\pi$-hop; large mask $\Delta$MSE $\Rightarrow$ PO mask;
        concept L0 with flat L1 $\Rightarrow$ raise EWMA $\lambda$;
        never VIMP-reweight the train features.
        Live MSR-VTT cross-modal: hop $0.0898\to 0.0896$ with $\pi_m$
        (video$\approx 0.71$, audio$\approx 0.26$)---signed gain, no new loss.
  \item[\textbf{O3.}] \textbf{Compound vs pure shift (uplift-monitor geometry).}
        Same cross-check pattern as AUUC$\times$IV tiers:
        L1 mass $\times$ L3 coupling $\to$ pure donor / contaminating donor /
        fusion soak / structural null, each with a default actuator.
  \item[\textbf{O4.}] \textbf{Online EWMA from attribution.}
        $(\hat c,\hat\delta,\Delta\pi)\to\texttt{attribution\_ewma\_rate}\to\lambda_{\mathrm{new}}$;
        optional $\Delta C$ spike alone raises $\lambda$ on the
        \emph{fusion adapter}, not every backbone.
  \item[\textbf{O5.}] \textbf{Eval surface still scarce.}
        Batch-hop causal geometry (domain RF + MMD + PO + LOGO/mask), not
        only Grad-CAM.
        Tables-only contamination board (shares + $C_{m\to m'}$ + actuator)
        sits next to existing MSR-VTT attribution tables.
\end{enumerate}

\paragraph{One-line product claim.}
Cross-modal contamination attribution turns FSDS modality shares and PO masks
into a \emph{layer$\to$actuator} router: blame the right edge, spend the
cheapest hop fix, escalate relearn only when $\pi$+mask fail under concept
reject.
