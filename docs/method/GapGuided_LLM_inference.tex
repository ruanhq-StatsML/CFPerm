\maketitle
\noindent Not TMLE, not causal, not online learning.
$W$ is a batch tag; $\hat e\approx P(W{=}1\mid X)$.
Adaptation: freeze $\pi$ from a domain pair, then feed a \emph{single} reader
the concatenated \emph{raw} blocks $E=E(\pi)$.
The reader is not updated from the query stream; $\pi$ is not updated either.
An opinion pool of $\hat e_m$ is a mixture of scores, not this map.

\section{Raw block + one reader}
Let $E=E(\pi)$. The observation is
$\mathrm{pack}(x)=\mathrm{concat}_{m\in E}\mathrm{serialize}(x_{B_m})$.
Output is $f(\mathrm{pack}(x))$ with one $f$. Dropped blocks are absent.
This restricts the $\sigma$-algebra of a frozen reader. It is not Hedge,
not a bandit over specialists, and not a per-query update of $\pi$.

A query updates $E$ only: $r=\lambda\pi+(1-\lambda)s(x)$, then
$E_{\mathrm{query}}=\mathrm{pack}(r)$. Stage A evaluates block prediction
$\hat e_m$; Stage B evaluates the adapted read after that update.
$\lambda=1$ is prior-only; $\lambda=0$ is a hard query gate (often noisier).

\section{Same expert versus packing}
A \emph{same expert} is $\hat m=\arg\max\pi$, then $f\in\mathcal{G}_{\hat m}$
(functions of $X_{B_{\hat m}}$ only) for every query. That template does not
depend on $x$. An instance gate $\hat m(x)=\arg\max s_m(x)$ is a different object.

Context packing is one reader on concatenated raw blocks
$E=E(\pi)$, not an opinion pool of $\hat e_m$. Disabled channels are omitted,
not emitted as empty headers. Abstain means the gap is not localized: do not
drop a block (pack all, or HITL). Forced top-1 on a diffuse shift discards signal.
