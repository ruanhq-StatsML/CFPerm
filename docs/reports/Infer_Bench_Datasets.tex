\begin{abstract}
Four public NLP benchmarks are frozen as $n=300$ local JSONL slices for inference-side landing work:
HaluEval~\citep{li-etal-2023-halueval},
SQuAD~\citep{rajpurkar-etal-2016-squad},
HotpotQA~\citep{yang-etal-2018-hotpotqa},
and TruthfulQA~\citep{lin-etal-2022-truthfulqa}.
This note posts the slice inventory, characterization of those 300-row exports, and the OnlineRFPerm numbers already run on HaluEval QA (plus HH-RLHF~\citep{bai2022hh-rlhf} as the alignment counterpart, not a fifth export).
These tools detect / localize / rank under shift; they are not fact checkers.
\end{abstract}

\section{Scope}
The four exports live at \texttt{data/hf\_cache/infer\_bench\_export/*.jsonl}.
BibTeX is in the same folder (\texttt{infer\_bench.bib} comprehensive; \texttt{recommended.bib} venue keys only).
Related follow-ups kept in the comprehensive file: SQuAD~2.0~\citep{rajpurkar-etal-2018-know} and HaluEval~2.0~\citep{li-etal-2024-dawn}.
HaluEval QA is itself derived in part from HotpotQA, so both citations are appropriate when using that slice.
