\begin{abstract}
This report inventories an open, implemented toolkit for distribution-shift diagnosis and adaptation, and answers a product question: in LLM \textbf{inference/prediction, alignment, hallucination monitoring, synthetic-data quality, and representation consistency}, what can land now, how, and what must not be over-claimed.

Five capability layers: (i)~\meth{RFPerm}---model-agnostic predictive-degradation permutation tests; (ii)~\meth{OnlineRFPerm}---streaming monitoring with online FDR; (iii)~\meth{PO-learner / CFPerm / DRPerm / RRPerm}---treat batches as \(T\in\{0,1\}\) and use causal objective functions as distributional distances plus OOD variable importance; (iv)~\meth{FSDS}---feature selection under covariate shift \(P(X)\) and concept drift \(P(Y\mid X)\); (v)~\meth{multi-layer / multi-scenario / feature-bank graph methods}---ASSOC/HSIC chains and hierarchical subset localization across user--item--session or modality towers.

\textbf{Non-negotiable stance.} These tools \textbf{detect, localize, reweight/gate, and schedule compute}. They are \textbf{not} fact checkers, and they do \textbf{not} uniquely decompose covariate vs.\ concept to single features without extra structure. KL additivity does not transfer to arbitrary distances; full-space unique attribution is impossible---\textbf{subset localization} is the correct production move.

\textbf{Priority landings (data ready):}
\begin{enumerate}
  \item Streaming hallucination / error-rate \textbf{regime} monitors (OnlineRFPerm + \(\texttt{po\_risk0}\) ranking);
  \item Synthetic vs.\ human preference \textbf{quality gates} (RFPerm-as-Judge);
  \item Representation batch geometry (embedding PC1--PC3) before predictive-shift tests;
  \item Multimodal towers---\emph{which layer moved} \(\to\) KV refresh / LoRA budget;
  \item RecSys feature banks (TencentGR-class): RF-domain for \(P(X)\), PO-risk for \(Y\)-gap;
  \item Gated \(\sqrt{\mathrm{PO}}\) reweighting: uniform when quiet; heat on concept hops; anneal.
\end{enumerate}
\end{abstract}

\section{Problem and boundaries}
\label{sec:boundary}

\subsection{Four product questions}
\begin{enumerate}
  \item \textbf{Is inference/prediction drifting?} When must a deployed \(\hat f\) refresh on streaming \((X_t,Y_t)\)?
  \item \textbf{Is alignment consistent?} Human prefs, synthetic prefs, judge models, online feedback---same law?
  \item \textbf{Did hallucination/error enter a new regime?} Not row-wise true/false---did \(P(Y\mid X)\) jump?
  \item \textbf{Is data quality consistent?} Feature stores, embedding batches, modality towers, synthetic corpora vs.\ reference.
\end{enumerate}

\subsection{Claims we refuse}
\begin{itemize}
  \item No story ``feature \(j\) causes hallucination.''
  \item No unique full-space split of \(P(X)\) vs.\ \(P(Y\mid X)\) from raw error alone.
  \item DRE / PSI / KL are not sufficient statistics for concept drift.
  \item \(\texttt{po\_risk0}\) is residual strength vs.\ the previous probe---not a factuality score.
\end{itemize}

\paragraph{Default production pipeline.}
\begin{enumerate}
  \item \textbf{Geometry pre-check:} PCA (PC1--PC3) + domain AUC on embeddings---alignment viz, not the final call.
  \item \textbf{Regime test:} OnlineRFPerm (or gated consecutive OOS ratio) decides fire.
  \item \textbf{Axis diagnosis:} stop if quiet; if fire, RF-domain (\(P(X)\)) and PO/R (\(P(Y\mid X)\) proxy) in parallel.
  \item \textbf{Feature/layer localization:} FSDS top-\(k\) + family mass; multi-layer \(\Rightarrow\) leave-one-group-out.
  \item \textbf{Action:} quiet \(\to\) uniform; heterogeneous concept \(\to\) \(\sqrt{\mathrm{PO}}\) weights; global map flip \(\to\) drop-old; modality drift \(\to\) refresh that tower's KV / update budget.
  \item \textbf{Anneal:} next hop's \(e_{\mathrm{prev}}\) is large, ratio falls, return to uniform.
\end{enumerate}

\section{Method cards}
\label{sec:cards}

\subsection{RFPerm}
Compares validation/OOB error on a reference batch to predictive error on a new batch via permutation. Density-aware; sensitive to both covariate and concept; does \textbf{not} name the axis alone.

\textbf{LLM use.} Prompts/representations as \(X\); correctness / preference / hallucination labels as \(Y\). Strong at \(n\sim 30\)--\(40\); fits per-observation synthetic-data gates (RFPerm-as-Judge).

\subsection{OnlineRFPerm}
Streaming extremity of predictive error vs.\ the deployed model; online FDR (SAFFRON/ADDIS, async variants) controls false alarms. Modality-agnostic whenever a predictive model and labels (or proxies) exist.

\textbf{LLM use.} Online judge scores, tool-success, refusal rate, hallucination rate as \textbf{regime} monitors; optional clever-covariate injection into a light adapter.

\subsection{PO-learner (DRPerm / RRPerm / CFPerm)}
Old batch \(T=0\), new \(T=1\). Doubly robust / R-learner objectives with permute-then-refit; VIMP reads as \textbf{OOD variable importance}. Meta-learners estimate distances, not causal effects. R-risk is more \(P(X)\)-insensitive under projection heuristics---a concept-axis proxy, not a uniqueness theorem.

\textbf{LLM use.} Alignment shift (same prompt law, changed preference/correctness map) vs.\ traffic mix shift. Instance \(\texttt{po\_risk0}_i=|Y_i-\mu_0(X_i)|\) (or \(1-p\) for class) drives ranking and gated weights.

\subsection{Gated \(\sqrt{\mathrm{PO}}\) reweighting (shipped locally)}
Fire only if consecutive OOS \(e_{\mathrm{now}}/e_{\mathrm{prev}}\ge\gamma\) (default \(1.5\)); on fire, \(T=1\) gets \(w=\sqrt{\texttt{po\_risk0}}\) (mean 1); quiet \(\Rightarrow w=1\). Under squared loss, excess risk \(\Delta_t^2=\mathbb{E}_t[(\mu_t^\star-\mu_0)^2]\)---the gate opens only when concept OOD is large relative to noise. DRE sees only \(p(x)\): near-uniform on pure concept; can hurt on covariate. Two levers: soft \textbf{reweight} vs.\ hard \textbf{drop-old}. No always-on IPTW; no ultra-thin PO-tail subsets.

\subsection{FSDS}
\textbf{Covariate:} RF-domain OOB-VIMP, MMD/HSIC-LOCO, Boruta/ShadowVIMP---strong and often cheaper than FSL-Net/DataFix.

\textbf{Concept:} PermuCATE, DRPerm-LOCO, GRF VIMP, R-risk LOCO, Delta-Shapley, Knockoff/L1---meta-learners shine on nonlinear concept drift.

\textbf{Reading discipline.} Rank VIMP, then post-hoc \(\mathbb{E}[X\mid Q_1]\) vs.\ \(\mathbb{E}[X\mid Q_4]\); mass + directional means describe ``who arrived later,'' not causation. Empirically on TencentGR clocks: cross / decay / in-session conversion carry the gap; last-touch attribution families are not the shift source.

\subsection{Multi-layer / multi-scenario / feature-bank graphs}
Feature stores are hierarchical (user / item / session / merchant; or audio / image / text). Unique single-feature attribution on the full space is impossible; \textbf{hierarchical subset localization} is the right move.

\textbf{ASSOC / HSIC chains.} Pairwise HSIC across layered metrics; threshold to edges; connected components are metric chains (e.g., delivery--rating--orders--GMV). Association only---no directed causal claim.

\textbf{Leave-one-group-out.} Block/modality contribution to shift; conditional drill (region then category) avoids confounding levels.

\textbf{Continuous multimodal inference.} FSDS shares \(\pi_m\) decide which tower to re-encode per window, which KV to invalidate, which tower gets test-time update budget; static captions encode-once. Attribution-Guided Online Distillation (AGOD) routes student losses with modality gaps as clever covariates.

\subsection{B. Hallucination and ``looks like an answer''}
\begin{itemize}
  \item \textbf{B1 Regime-level hallucination-rate monitor \(\star\).} Synthetic concept cut: quiet then noisy. OnlineRFPerm/gate fires at the cut; instance \(\texttt{po\_risk0}\) ranks audit candidates (proto AUROC \(\sim 0.63\)--\(0.64\)). \textbf{Not} fact checking.
  \item \textbf{B2 Hallucination-labeler drift.} Same generations, human/auto \(Y\) changes \(\to\) PO/R; generation mix changes \(\to\) RF-domain.
  \item \textbf{B3 Refusal / safety-policy hops.} Safety action as \(Y\); monitor whether the policy head entered a new operating point---do not confuse traffic mix with ``model got worse.''
\end{itemize}

\subsection{C. Alignment and preference consistency}
\begin{itemize}
  \item \textbf{C1 Human vs.\ synthetic preference.} RFPerm-as-Judge: small-\(n\) test that synthetic prefs are not predictively off the human batch.
  \item \textbf{C2 SFT/RLHF/DPO version gates.} Old vs.\ candidate preference data: FSDS lists which prompt features carry the gap; fail closed on merge.
  \item \textbf{C3 Judge-model calibration.} Judge score as \(Y\); OnlineRFPerm vs.\ a gold set; high PO \(\Rightarrow\) sample audit, not full relabel.
  \item \textbf{C4 Instruction-following vs.\ style covariates.} Style/length/language mix \(\to\) RF-domain; correctness map \(\to\) PO. Do not explain accuracy drops with PSI(length).
\end{itemize}

\subsection{D. Data quality and representation alignment}
\begin{itemize}
  \item \textbf{D1 Embedding batch geometry \(\star\).} Point-cloud / text / multimodal embeddings: PC1--PC3 + domain AUC; only then RFPerm/FSDS. Fix the pipe if geometry is broken.
  \item \textbf{D2 Feature-bank health (TencentGR-class) \(\star\).} Combinatorial features \(\to\) FSDS: RF for cohort portrait, PO for conversion gap; family mass drives feature workorders.
  \item \textbf{D3 Synthetic corpus diversity vs.\ toxic patterns.} RFPerm on quality labels; FSDS localizes toxic pattern features (length, template \(n\)-grams, embedding clusters).
  \item \textbf{D4 Train--serve feature parity.} Same feature names offline vs.\ online as \(T=0/1\); high RF-domain VIMP = pipeline-bug suspect list.
\end{itemize}

\subsection{E. Multimodal and continuous-inference scheduling}
\begin{itemize}
  \item \textbf{E1 Tower attribution (MSR-VTT / ChronoBerg-class) \(\star\).} Block FSDS + PO; shares \(\pi_v,\pi_a,\pi_t\) set re-encode and update masks.
  \item \textbf{E2 Continuous VLM inference.} Static text encode-once; vision/audio refresh per window; KV invalidation on session-clustered monitors (avoid global pooled cancellation).
  \item \textbf{E3 AGOD distillation routing.} \(\alpha_m=\mathrm{softmax}(g_m/\tau)\) with \(g_m\) from domain AUC\(\cdot\)VIMP + \(\gamma\cdot\)PO-risk; fall back to RF-domain under poor overlap.
\end{itemize}

\subsection{F. Multi-layer business graphs (recs / risk / commerce)}
\begin{itemize}
  \item \textbf{F1 Hierarchical subset localization.} Significant week batch \(\to\) user-region first, then category; emit \{\texttt{subset}, \texttt{split rule}, \texttt{stability}\} to owners.
  \item \textbf{F2 ASSOC metric chains.} HSIC edges surface cross-layer coupling (fulfillment--rating--orders--GMV); alert on chains, not single KPIs.
  \item \textbf{F3 Fraud mix vs.\ fraud tactic.} Matches the open PDFs: cohort mix = covariate; tactic = concept; separate tickets.
\end{itemize}

\section{Executable playbooks}
\label{sec:playbook}

\subsection{Playbook 1: LLM output-quality stream}
\begin{enumerate}
  \item Define \(Y\in\{0,1\}\): correct / non-hallucinated / preference win (labels or weak supervision).
  \item \(X=\) prompt embedding + light metadata (length, tool calls).
  \item Fit shallow RF probe \(\mu_0\) on reference window; stream \(e_{\mathrm{now}}/e_{\mathrm{prev}}\).
  \item On fire: alert + Top-\(k\) audit by \(\texttt{po\_risk0}\); optional \(\sqrt{\mathrm{PO}}\) refit of a light head.
  \item Attach online FDR so diurnal traffic jitter does not page on-call.
\end{enumerate}

\subsection{Playbook 2: Alignment data version gate}
\begin{enumerate}
  \item Old preference set \(T=0\); candidate merge set \(T=1\).
  \item RF-domain: very high AUC with top feature ``source=synthetic'' \(\Rightarrow\) portrait contamination.
  \item DRPerm/PermuCATE: significant concept axis \(\Rightarrow\) preference map moved; human review, no silent merge.
  \item Merge only if both axes quiet (or only explained covariates with owner sign-off).
\end{enumerate}

\subsection{Playbook 3: Multimodal continuous inference}
\begin{enumerate}
  \item Per window extract \(X_v,X_a,X_t\); block RF-domain + PO vs.\ reference.
  \item Obtain \(\pi_m\); if \(\pi_t\approx 0\), caption encode-once.
  \item High \(\pi_v\) \(\Rightarrow\) refresh vision KV / raise vision update steps.
  \item Spurious text VIMP rise is a \textbf{leakage diagnostic}, not a reason to spend budget on the language tower.
\end{enumerate}

\subsection{Playbook 4: Feature-bank drift workorder}
\begin{enumerate}
  \item Fix a business clock (time quantiles / experiment buckets).
  \item Emit RF-mass and PO-mass by family with Q1\(\to\)Q4 means.
  \item Families with negative LOGO \(\Delta\) are not ``root causes.''
  \item Ticket only high-mass families with readable direction (decay clicks, in-session conversion, crosses).
\end{enumerate}

\section{Engineering conclusions aligned with impossibility}
\label{sec:impossibility}

\begin{enumerate}
  \item \textbf{Unique error decomposition is impossible:} model change vs.\ data change without structure.
  \item \textbf{Unique axis decomposition is impossible:} except special divergences (e.g., KL), raw error does not uniquely split \(P(X)\) vs.\ \(P(Y\mid X)\).
  \item \textbf{Unique single-feature decomposition is impossible:} ship VIMP + subset localization; never ``feature \(j\) is 23\% of the drift'' as a KPI.
  \item \textbf{What remains feasible:} jointly sensitive tests (RFPerm); axis proxies (R/PO vs.\ domain); subset/layer localization; gated adaptation.
\end{enumerate}

\section{Risks, fallbacks, MLOps hooks}
\label{sec:mlops}

\begin{itemize}
  \item \textbf{Poor overlap:} unstable meta-learners---fall back to RF-domain / refuse fire / widen reference.
  \item \textbf{Empty-room denominators:} classification \(e_{\mathrm{prev}}\approx 0\) false-fires---set \(e_{\mathrm{floor}}\).
  \item \textbf{Always-on IPTW:} loses to uniform on quiet clocks---default uniform; heat only on gate.
  \item \textbf{Parallelism:} permutation tests parallelize; literature cites \(\sim 60\)--\(70\%\) wall-clock cuts.
  \item \textbf{Hooks:} feature-quality boards, merge gates, online alerts, multimodal schedulers, synthetic-data acceptance.
\end{itemize}

\section{Conclusion}
\label{sec:conclusion}

RFPerm / OnlineRFPerm / PO-learner / FSDS / multi-layer graphs already form a closed loop:
\textbf{test \(\to\) localize \(\to\) gated adapt \(\to\) schedule}.
In LLM settings the valuable artifact is not ``another hallucination score,'' but:

\begin{quote}
With data and labels ready: regime detection under statistical gating, interpretable feature/modality localization, spend reweighting and compute only on true fires, and anneal on the next hop.
\end{quote}

FSDS is the default diagnostic layer for \textbf{feature-bank and multi-tower consistency}; PO-learner for \textbf{alignment maps} and \textbf{concept hops}; OnlineRFPerm for \textbf{online regimes}; multi-layer ASSOC for \textbf{cross-scenario drills}. Keep ``detection \(\neq\) causation, localization \(\neq\) unique decomposition,'' and the toolkit ships to production instead of staying in paper figures.
