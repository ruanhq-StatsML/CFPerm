## 口径

```
seed: hop_ratio → ignore 工单/退款 bump；fire_halluc → 火情标签率；
      rag_low/ok/thr → 动作路由（retrieval vs rollback/audit）
毛¥ = 费率差 × acted会话 × 单价
净¥ = 毛¥ − acted 审计人力
全成本净¥ = 毛¥ − 审计 − 动作日成本
```
