\paragraph{Setup.}
HaluEval + SQuAD CPU live-infer streams. Quiet ref fits a frozen RF probe; trail yields a 1-d error/MSE stream. Baselines follow \texttt{onlinePermOOB\_algo.py}: BOCPD (\texttt{bayesian\_changepoint\_detection}), PageHinkley/ADWIN (\texttt{river}), DDM/STEPD/HDDMA/ECDDWT (\texttt{frouros}). OnlineRFPerm uses consecutive OOS error-ratio on the same $(X,y)$. KPI: delay (batches after cut) and quiet false fires.

\paragraph{Takeaway.}
Read delay jointly with quiet false fires. OnlineRFPerm watches $P(Y\mid X)$ hops; BOCPD/ADWIN/PH/frouros watch a scalar error stream from a frozen probe---the comparison the OOB algo script is built for.
