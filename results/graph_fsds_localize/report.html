用户 Jaccard = 0 是对的：用户跨商户随机挂，变动不在用户粒。concept 比 covariate 难收，因为 \(X\) 没动。

为什么有用

  1. 一半商户在走时，全窗 MMD 可能还没到冻层阈值。库按列、按商户切开，子集先报。
  2. 「金额走了」和「南区走了」是两件事。图 1/2 管列，图 3 管商户。
  3. 钟和现有冻层看板同一套：MMD / PO / 条件均值 vs 冻结参考窗。没有新的因果故事。
  4. 九列各打一次一维 MMD；16 个商户排个序。算得起。

局限：这是定位，不是「金额贡献了 60%」那种唯一分解。新商户没有自己的历史，不进商户排名。
