# 拆成交：任意/同品、续逛、热度

做特征就是在对这单从哪来、买完人还在干什么。asof 只是最近邻，**不是归因 ground truth**，也不是「多模态」。  
任意 vs 同品是两个问题；续逛不是转化。没有「哪次点击导致购买」的 label，别拿 AUC / F-score 审生意。

计算见 `POST_CALC.md`。评估协议、满窗、成交量、序列归因见 `EVAL_AND_SEQ.md`。事件 `0=曝光 1=点击 2=转化`。转化一行。

---

## 1. 任意 vs 同品：两问，不是两种模型

```
同品  by=(user, item)   这件商品的漏斗闭没闭合
任意  by=user           这个人在不在信息流里活动
```

「没点过这件」可以同时「刚点过别的」。只做同品 last-click，会把后一种判成空路径。只做任意，会把「点的是另一件」说成「点了这件」。

| | 同品 | 任意 |
|---|---|---|
| 买前曝光 | 看过这件没有 | 最近还在看货架 |
| 买前点击 | 点过这件没有、点完多久买 | 最近动过手没有 |
| 买后点击 | 这件买完还看不看 | 人还在不在平台 |

这批 prefix（12866 单）把两问拆开就清楚了：同品点过再买 **14 单（0.11%）**；只点过别的再买这件 **51.5%**；序列里没有任何点击 **48.3%**。同品曝光能对上的也只有 0.2%。  
人在逛（任意），但这件 SKU 的漏斗对不上（同品）。这是拆成交。不要叫多模态。

`dt_any` 中位约 4 天：连任意 last-click 也不是当场点完就买。

空路径单独一档，**dt 禁止填 0**（0 分钟 = 刚点完就买）。

## 2. 续逛 vs 转化

转化是锚点，不是「逛」的别名。

- **转化**：这一刻成交。
- **续逛**：转化之后还在**同一场**里划（下一次曝光/点击的 `dt ≤ 30min`，场没关）。
- **回访**：下场再来（`dt > 30min`）。

转化前的当场点击 `sess_clk_before`：这场已经在逛，成交是插进来的一笔。转化后短窗里的点，优先当续逛，不当「买带动了点」。

这批：`sess_clk_before=0` 占 **98.4%**，`sess_pos` 中位 = 1。转化经常自己开一场，前面没有「先点几下再买」。它不是逛的高潮，是一条相对孤立的成交事件。

那 1.6% 当场已经点过的单，买后 1d 任意点击 29% vs 其余 11%——热场里买完还会点，这是续逛/热度，不是购买效应。

拆的时候：

| 量 | 当什么 |
|---|---|
| `y_post_clk_5m` / `next_clk_same_sess` | 续逛 |
| `y_post_clk_1d` 且 `dt_next > 30min` | 隔场还在不在（平台回访） |
| `y_post_same_*` | 这件 SKU 的余温，和续逛不是一回事 |

不要用邻接 Markov `trans_cnv_to_exp` 替代：那是下一条事件，不是窗、不是场。

## 3. 热度、泄漏，还有什么

**用户热度（基线，要控）。** 有的人本来就爱点。买前 7d 点击量、历史上买完还点的比例，预报的是「这类人」，不是「这一单」。刻画要按热/冷分层看买后率；进 X 当控制，别解释成购买带动。

**泄漏（X 里进了答案）。** 本单的 `n_after` / `dt_next` / `y_post` 进 X；`lag` 没 `shift(1)` 把本单 Y 算进去；跟不满窗当 0（把「还没机会点」当成「不想点」）；同一人的转化随机切进 train/test。这些会让任何分看起来很好，和生意无关。

**还有同样直观的：**

| 混杂 | 样子 | 怎么办 |
|---|---|---|
| 连单 | 后一单买前的点，算进前一单的 after | 任意 lift 脏；同品干净；或只计下场点击 |
| 右删失 | prefix 末尾的单跟不满 | 跟不满不当负例 |
| 左切 | prefix 切掉更早的点，假「空路径」 | 空路径单独档，别当「从没点过」 |
| 覆盖 | 成交 SKU 不在曝光日志里 | ≠ 用户没看见这件；同品曝光对不上先当覆盖问题 |
| 场切 | 30min 切错，一场变两场 / 两场粘一场 | 续逛定义跟着切；可再报 5m/1h 对照 |
| 次数当结构 | `pay_cnt` 是量，`cnv_share` 才是轨迹里买占多大 | 别把单量当「爱买的人」 |

没有「哪次触点导致转化」的 label，也没有「购买导致后续点击」的 label。asof 是最近邻描述。  
生意假设用**构成和率**核对：同品对得上多少、当场 0 点多少、after vs before、空路径的买后率。  
「跟满窗后还会不会点」是另一件可观测的事，可以预报，**预报成功 ≠ 归因对了**。不要 AUC 审 last-click，更不要 F-score。

这批构成已经否掉几条常假设：SKU 点完就买（0.11%）；曝光即买这件（0.1%）；逛热了再买（98% 当场 0 点）；买完还看这件（同品买后 ~0.1%）；买完抬平台点击（after≈before）。剩下站得住的是：任意路径一半在、空路径一半在、空路径买后更低（6.8% vs 15.7%）。

## 4. 曝光 ～ 点击 ～ 购买：特征列表

粒：转化一行。W∈{5m, 1h, 1d, 7d}（路径/买后）；漏斗计数另用 {1d, 7d, 30d, life}。  
空 asof → 空，不填 0。买后 y / n_after 只留跟满 W 的单。  
`C(t)=#{ts≤t}`；`n_(t-W,t]=C(t)-C(t-W)`；`n_(t,t+W]=C(t+W)-C(t)`。

### 4.1 曝光

| 名 | 怎么算 | 问什么 |
|---|---|---|
| `n_exp_before_W` | 任意曝光，`(t-W,t]` | 买前还在不在看 |
| `n_exp_same_before_W` | 同品曝光，`(t-W,t]` | 这件刚看过没有 |
| `n_exp_same_le` | 同品曝光，`ts≤t` | 这件历史上看过几次 |
| `wo_prior_exp_item` | 同品 last-exp 空 | 序列里没看过这件 |
| `dt_exp_item` | `t − last_exp_item`，分钟 | 这件上次看到买隔多久 |
| `dt_exp_any` | `t − last_exp_any` | 货架上次刷到现在 |
| `exp_item_within_5m/1h` | `dt_exp_item≤桶` 且非空 | 刚看这件就买 |

### 4.2 点击

| 名 | 怎么算 | 问什么 |
|---|---|---|
| `n_clk_before_W` | 任意点击，`(t-W,t]` | 买前动手量（热度控制） |
| `n_clk_same_before_W` | 同品点击，`(t-W,t]` | 这件刚点过没有 |
| `n_clk_same_before` | 同品点击，`ts≤t` | 这件历史点次 |
| `wo_prior_clk` | 同品 last-clk 空 | 这件从未点过就买 |
| `dt_item` | `t − last_clk_item` | 这件点完多久买 |
| `dt_any` | `t − last_clk_any` | 上次任意点完多久买 |
| `dt_first` | `t − first_clk_item` | 这件从第一次点到买 |
| `item_within_5m/30m/1h/1d` | `dt_item≤桶` 且非空 | SKU 短路径桶 |
| `any_within_5m/1h` | `dt_any≤桶` 且非空 | 任意短路径桶 |
| `has_any_clk` | `dt_any` 非空 | 序列上有没有点过（任意） |

### 4.3 购买（锚上已知）

| 名 | 怎么算 | 问什么 |
|---|---|---|
| `n_prior_cnv` | 此前转化条数 | 是不是回头客 |
| `log1p_price` | `log1p(max(price,0))` | 客单（空当 0 只用于 log） |
| `life_n_cnv` / `life_cnv_share` | 用户级，进用户表 | 量 vs 轨迹里买占多大 |

### 4.4 当场（续逛的左边）

| 名 | 怎么算 | 问什么 |
|---|---|---|
| `sess_pos` | 本场第几条（含本条转化） | 一场开头买还是逛到半场买 |
| `sess_clk_before` | 本场、本条前点击数 | 这场已经在点了吗 |
| `sess_exp_before` | 本场、本条前曝光数 | 这场已经在看了吗 |
| `gap_prev` | 上一条事件到转化的秒 | 刚动过还是冷启动开场 |

### 4.5 买后（描述 / 预报目标；**不准进本单 X**）

| 名 | 怎么算 | 问什么 |
|---|---|---|
| `y_post_clk_W` | 任意下一次点击 ≤W；跟不满且没点到丢 | 人还在不在点 |
| `y_post_same_W` | 同品下一次点击 ≤W | 这件还看不看 |
| `y_post_exp_W` | 任意下一次曝光 ≤W | 还在不在刷 |
| `next_clk_same_sess` | `dt_next_clk ≤ 30min` | 续逛 vs 隔场 |
| `n_clk_after_W` / `n_clk_before_W` | 同长窗 | 点量抬没抬（任意脏、同品净） |
| `lift_W` | `n_after/(n_before+1)` | 同上，跟满才留 |
| `y_post_cnv_W` | 下一次转化 ≤W | 复购（任意/同品各一条） |

### 4.6 滞后（上一单的买后，给这一单）

| 名 | 怎么算 | 问什么 |
|---|---|---|
| `lag_post_clk_1d_rate` | 此前各单 `y_post_clk_1d` 的均值，`shift(1)`，跳过 NaN | 这人买完爱不爱点 |
| `lag_post_same_1d_rate` | 同品版 | 这人买完还看不看同品 |

用户表：未删失转化上对 4.5 做 mean/median，再 join。交叉最后乘。  
主模型这批只该认真用：任意路径（`has_any_clk`,`dt_any`）、买前任意量、当场、空路径档、滞后。同品列留下做监控，占比≈0 时别当主信号。

## 5. 落地顺序

1. 转化表：同品/任意 × 曝光/点击 的 backward asof + 空档。  
2. 当场四列。  
3. Forward：点/曝/买，跟满窗才留 y。  
4. 打构成表：同品对上 / 仅任意 / 全空；当场 0 点占比；after vs before。  
5. 构成否掉的假设，列留监控；对得上的路进描述和（若要预报买后点）进 X。
