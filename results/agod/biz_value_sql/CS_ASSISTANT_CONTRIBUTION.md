# 客服助手增量贡献账（可复现）

产品面：`shop_assistant`（客服助手）。  
对照：同一幻觉制度跳变期内，**动作落地** vs **同条件不动作**。  
单位经济：工单 ¥25 / 退款 ¥80 / 机器人成功承接会话 ¥3.5。

## 落地产出（业务 KPI）

| 指标 | 数值 |
|------|------|
| 少产生工单 | **103.0** 单 |
| 少产生退款 | **73.0** 单 |
| 多机器人承接会话 | **174.0** 次 |
| 区间增量贡献 | **¥9024.0** |
| 其中：少工单 | ¥2575.0 |
| 其中：少退款 | ¥5840.0 |
| 其中：多承接 | ¥609.0 |
| 每千会话增量贡献 | **¥6446.0** |
| 30 天跑率（按 acted 日均外推） | **¥38674.0** / 月 |
| 30 天少工单（外推） | 441.4 单 |
| 30 天少退款（外推） | 312.9 单 |
| 承接率提升 | 12.43 pp |
| 对照天数 acted / ignored | 7 / 7 |
| acted 会话量 | 1400.0 |

## Before → After 费率（三臂）

| 费率 | quiet（平稳） | fire+不动作 | fire+动作落地 |
|------|---------------|-------------|---------------|
| 工单率 | 1.50% | 9.57% | 2.21% |
| 退款率 | 0.61% | 6.64% | 1.43% |
| 机器人承接率 | 97.89% | 84.21% | 96.64% |

读法：制度跳变后若不动作，工单/退款率显著恶化；动作落地后费率回到接近平稳期，这就是增量贡献的来源。

## 口径

```
增量贡献¥ =
  (ignored工单率 - acted工单率) × acted会话数 × 工单单价
+ (ignored退款率 - acted退款率) × acted会话数 × 退款单价
+ (acted承接率 - ignored承接率) × acted会话数 × 承接会话价值
```

## 一句对外

客服助手在幻觉制度跳变的 7 个动作日里，相对同条件不动作：少了
103.0 单工单、73.0 单退款，
多承接 174.0 次会话，贡献约 ¥9024.0；
按当前流量外推约 ¥38674.0/月。
